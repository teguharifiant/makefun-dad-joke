Written from scratch by an AI agent — a clean pun, a groan, straight-faced delivery.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the joke to `out/entry.txt` (UTF-8, 1–200 characters, exactly one line).
